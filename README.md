# Prof. Victor — Website Designer Portfolio

A real responsive HTML/CSS/JavaScript website with a blue, image-led hero and functional navigation, services, sample project gallery and a contact form that prepares an email.

## Open
1. Unzip the download.
2. Double-click `index.html` to preview. Internet may be needed to load Google fonts; local fallback fonts are provided.
3. Edit files using VS Code.

## Before publishing
- Replace `your-email@example.com` in `script.js` with your real contact email. The form uses `mailto:` and **does not automatically send**.
- Replace the two sample projects in `index.html` with your **real** work, screenshots, client-approved descriptions and project URLs. Sample work is explicitly labeled and not a claim of completed client projects.
- Update bio/service claims as needed. There are no made-up testimonials, client counts, or experience statistics.
- Update the brand `toms-prof.` and display name `PROF. VICTOR` in `index.html` if needed.
- The hero portrait is an AI-edited version based on the supplied photo, intended without earrings. Check it matches your expectations before publishing.

## Hosting
Deploy the unzipped folder to Netlify (drag-and-drop), Cloudflare Pages, or GitHub Pages. All files use relative URLs and no build command is needed.
